## Why this exists

The PRI manuscript quotes numbers that come from banked JSON artifacts. One had silently drifted: the baselines table read `0.8975` for Llama's v3 sealed value where the artifact says `0.8963`. It survived multiple human and model reviews. The goal is to make that class of error **impossible to reintroduce**, mechanically, with no model in the loop.

## Design — three tiers, in this order

### Tier 1: unattributed-precision scan (no manifest needed)

Find every decimal in the `.tex` written to **exactly 4 decimal places** (e.g. `0.8963`, `+0.1571`, `-0.1658`). In this manuscript those are essentially always direct artifact quotes. For each, check that **some** value in **some** banked `sealed_gate.json` matches within `5e-5` (compare against `auroc`, both `ci` endpoints, `delta`, both `delta_ci` endpoints, `auroc_a`, `auroc_b`). Report any that match nothing, with the tex line number and surrounding context.

Skip content inside `%` comments, `\label{}`, `\ref{}`/`\Cref{}`, and `verbatim` environments.

### Tier 2: explicit claim manifest (the rigorous tier)

A manifest file `scripts/paper_numbers_manifest.yaml` (or `.json` if you prefer stdlib-only — see constraints) mapping each load-bearing claim to its artifact source. Entry shape:

```yaml
- id: baselines.llama.v3
  tex_context: "Llama 3.2 3B"        # substring that must appear on or near the line
  value: 0.8963
  run: 2026-04-26/run-09
  model_match: Llama                  # substring matched against per_model[].model
  json_path: E17_null_bare_rank1.auroc
  tolerance: 5e-5
```

The checker resolves each entry against the artifact and confirms (a) the artifact value matches `value`, and (b) `value` literally appears in the `.tex`. Both directions matter: (a) catches the paper drifting from the data, (b) catches the manifest going stale after an edit.

**You author the manifest** by reading the current manuscript and covering, at minimum: every cell of the E18 verdict table, every cell of the three-row E17b table (including CI endpoints and signs), every cell of the baselines table including its sign column, and every AUROC quoted in the abstract, §4 and §5. Authoring this manifest is itself an audit — **if any cell disagrees with its artifact, do not silently write the artifact value into the manifest: report the disagreement prominently in your summary.**

### Tier 3: derived-value recomputation

Some numbers are legitimately computed, not quoted. Support a small declarative list where each entry names a formula over artifact values and the expected published number. Cover at least:

- the `+0.32` matched-pair swing (run-05 delta to run-02 delta on Qwen)
- the `7.9` multiple of the `+0.02` bar (run-09 Qwen delta / 0.02)
- the CI-narrowing percentages `36%` observed and `42%` from `1 − 1/√3`
- the unoriented Qwen baselines `0.084` and `0.105` (i.e. `1 − auroc` where `sign == -1`)

## Constraints

- 🐍 **Python 3.9+, standard library only.** No PyYAML, no external deps — the repo's `requirements.txt` pins nothing and adding a dependency for a lint tool is not worth it. Use JSON for the manifest if that keeps it stdlib-only.
- 📖 **Read-only over artifacts.** The script must never open a `sealed_gate.json` for writing. This repo has a live hazard where a sibling script defaults its output path over the sealed artifact; do not repeat it.
- 🚦 **Exit code 0 on clean, 1 on any mismatch**, so it can run as a pre-commit hook or in CI.
- 🖨️ **Output is a report**, grouped by tier, naming tex line numbers and both values on every mismatch. Quiet on success apart from a one-line summary with counts per tier.
- 🧪 **Include a `--self-test` flag** that injects a known-wrong value into an in-memory copy of the tex and asserts the checker flags it. A checker that cannot demonstrate a failure is not trustworthy.
