## Hard rules for anyone executing

- Model-facing stimulus text stays plain — no emojis, no decoration; every character is tokens.
- Camera test on all shared-event text: counts/timestamps/quotes legal; frequency adverbs and character adjectives banned; evaluations must be generated by agents, not inherited.
- Named needs come from [[needs-inventory]] only. If you can see a visual, it is a strategy, not a need.
- Nothing resolution-shaped in any stimulus, ever — the Rosenberg endpoint (t_sol) must stay unscripted.
- Stakes are sharpened with props (timestamped artifacts), never proclamations or "don't resolve" instructions.
- Matched decoding parameters on both dyad sides, always (temperature asymmetry confounds every magnitude metric).
- Repo↔wiki separation: code lives in a repo, spec lives here; wiki→repo pointers fine, never the reverse.
