# GPU ledger

_Started 2026-10-10 (MK standing rule; see the GPU accounting rule in root `CLAUDE.md` HARD RULES). One row per GPU run, Modal or otherwise. Newest at the bottom; append, don't rewrite. Corrections go in a new row that names the row it corrects._

**Columns.** GPU-hours = wall-clock GPU-hours = (container wall-clock hours) × (GPU count), smoke and failed attempts included. **Basis** says how the number was obtained, and the three kinds are never added together without saying so:

- ✅ **measured** — read from the run's own timer or from Modal's billed usage.
- 📏 **log bound** — derived from driver-log timestamps; an upper bound on container time, not a billed figure.
- 🔮 **estimate** — a pre-run plan or work-order figure; nothing was measured.
- ❔ **not recorded** — the run happened, but no runtime was banked.
- 💳 **billed** — Modal dashboard cost by GPU type (Usage & billing, read 2026-10-10 via the signed-in browser). GPU-hours on these rows are *derived*: billed cost ÷ Modal's listed per-second rate on 2026-10-10 (A100-80GB $0.000694/s, A100-40GB $0.000583/s, A10 $0.000306/s). App-level costs include that app's CPU and memory.

Cost is filled only from a Modal invoice or dashboard figure, never from a rate card times an estimate.
