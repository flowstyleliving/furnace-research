# PRI v3 sealed gate — reproducibility check (2026-09-09)

_Status: `[VERIFIED]` — analysis-only re-derivation. **No gate was re-read and no model was re-run.** First reproducibility check on record for the PRI v3 line._

**Verdict: EXACT. 276 of 276 fields byte-equal** between the banked sealed artifact and a fresh re-score of the same parquets.

## Why this was run, and why it is not a re-run

MK asked whether the fix for the stale E17b ledger tag was to re-run PRI v3. **It is not.** E17b is a sealed, pre-registered, single-look confirmatory gate; re-running it and re-reading the gate reintroduces the multiple-looks problem the pre-registration exists to prevent — the same discipline that made grid B single-look in the DC lane. With seed 20260423, greedy decoding and a deterministic puzzle generator, a re-run also returns the same numbers.

The distinction this page rests on:

- 🚫 **Re-running the experiment** — regenerate from the models, re-read the gate. Damages the seal. Not done.
- ✅ **Re-running the analysis** — point the sealed-gate analyzer at the **banked** parquets and compare against the recorded outputs. Touches no verdict, because it compares to a recorded artifact rather than reading a gate. This is what was done.

## Procedure

```
python scripts/analyze_sealed_gate.py \
    --run-dir experiments/v3-main-run/2026-04-26/run-09 \
    --out <scratch>/rescored.json
```

⚠️ **The `--out` flag is mandatory here, and this is a real hazard.** The analyzer defaults to writing `run-dir/sealed_gate.json` — i.e. **it would overwrite the sealed artifact being verified**. The banked file was sha256'd before and after to prove it was untouched: `5e26e676e86130ac0ea72eea09a6df3cc830f6c452503518884c016bb763aa12`, identical on both reads.

Comparison was field-by-field over the full nested JSON (volatile keys `run_dir` / `generated_at` / `timestamp` excluded), not an eyeball of the printed summary.

## Scope — what this does and does not cover

- ✅ **Covers the sealed gate**: E18 on all three primaries and E17b on Qwen 2.5, from `2026-04-26/run-09`. This is the artifact the sealed verdict is defined on.
- ➖ **Does not cover the descriptive cross-architecture panel.** Phi-3.5-mini (`2026-04-27/run-01`) and Gemma 3-4B (`2026-04-27/run-02`) are single non-primary runs; the analyzer is primary-gated and refuses to write without a primary. Those cells are descriptive, not sealed.
- ➖ **Does not establish generation-side reproducibility.** Only the analysis step was re-derived. Whether MLX 4-bit generation reproduces bit-for-bit on this hardware is untested and should not be claimed.
- 🔒 **Moves no verdict.** E17b was already `[VALIDATED]` (tag corrected 2026-09-09); this check confirms the recorded numbers are re-derivable from the banked parquets, nothing more.
