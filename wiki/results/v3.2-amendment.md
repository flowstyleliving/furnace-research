## Motivation — the 3-Fisher / 3-Raw split is partly a geometric artifact

The [v3.1 definitive 2026-04-26 J_n verdict](v3.1-replicate.md) showed an architectural split across the six tested models in the sealed E17b head-to-head:

| Family | Fisher (`null_ratio_post_rank1`) wins | Raw (`null_ratio_raw_post_rank1`) wins |
|---|---|---|
| Llama 3.2 3B | ✓ | |
| Mistral 7B | ✓ | |
| Qwen 2.5 7B | ✓ (Δ=+0.150 post-J_n) | |
| Qwen 3 8B | | ✓ (Δ AUROC = −0.36 vs Fisher) |
| Phi-3.5-mini | | ✓ |
| Gemma 3 4B | | ✓ |

**Working hypothesis (open):** the split is *partly* a consequence of the **uncentered** Fisher approximation in the current implementation. The basis V_top in `null_ratio_and_energy` is the right singular vectors of `A = sqrt(diag(p)) · W_u`, which diagonalizes `Aᵀ A = W_uᵀ diag(p) W_u`. This is **not** the proper softmax Fisher — the centered form is `F_c = W_uᵀ (diag(p) − p pᵀ) W_u`. The `−p pᵀ` rank-1 correction has the largest magnitude when p is concentrated, which is precisely the regime where Qwen 3 lives (top-1 captures 83.2% of energy; pre-norm `|Δh|` ≈ 1000).

**Algebraic preview**: in a synthetic high-confidence regime (`p[7] ≈ 1.0`), the top eigenvalue of `F_uncentered` is `7.15` while the top eigenvalue of `F_centered` is `4.65e-4` — a **15,000× difference**. Whatever signal `null_ratio_post` reads off the uncentered top-eigenvector at high-confidence tokens is essentially noise from the wrong operator. (Smoke test: `/tmp/smoke_centered_fisher.py`, run 2026-05-07.)

If centered-Fisher recovers Qwen 3, the architectural split collapses from "model-family disagreement" to "geometric artifact of an approximation."

## What v3.2 adds

**Three new metric columns** in the per-row results parquet (DESCRIPTIVE-only; no sealed-gate authority):

| Column | Semantics | Closed form |
|---|---|---|
| `kl_discharged` | Total KL between p(h_prev) and p(h_t) at second order | `½·Var_p(W_u·∂h_post)` (nats) |
| `null_ratio_centered_post_rank{r}` | Fraction of KL not captured by top-r centered-Fisher directions | `(kl_total − kl_topr) / kl_total` |
| `fisher_energy_centered_rank{r}` | Cumulative eigvalue energy of `F_c`, top-r | `Σ_{i≤r} λ_i / Σ_i λ_i` |

| Column | Semantics |

`K=512` matches the support truncation in `null_ratio_and_energy` at `max_rank=32` (the sealed primary rank window). This unlocks any further KL-grounded post-hoc analysis from v3.2 dumps without re-running the model.

## Mathematical basis

KL identity (Cover & Thomas §11; Amari, *Information Geometry* §3):
$$\mathrm{KL}(p_\theta \,\|\, p_{\theta+\varepsilon}) = \tfrac{1}{2}\, \varepsilon^\top I(\theta)\, \varepsilon + \mathcal{O}(\varepsilon^3)$$

For `p_t = softmax(W_u · n(h_post))` and `ε = ∂h_post`:
- `I(h_post) = W_uᵀ (diag(p_t) − p_t p_tᵀ) W_u`  *(centered Fisher)*
- `KL_total ≈ ½·∂h_postᵀ I(h_post) ∂h_post = ½·Var_{p_t}(z)`,  `z = W_u·∂h_post`

So the total KL discharged is one inner product. **Note**: `kl_discharged = 0.5·d_F_full²` — identical in numerical content to the existing `d_F_full` column, surfaced here in nat units with the explicit KL label. This is a clarifying alias, not new computation.

The rank-r decomposition uses the top-r eigenvectors of `F_c`. Routed through the existing SVD of `A = sqrt(diag(p))·W_s`:
- `m = W_sᵀ p_s` lies in `span(V)` (since `m = Aᵀ sqrt(p_s)`), so the perturbation is confined to the `(rank A)` subspace.
- In `V` coordinates: `F_c | V = M = Σ² − (Σg)(Σg)ᵀ` where `g = Uᵀ sqrt(p_s)`, `A = U Σ Vᵀ`.
- Eigh on `M` (size ≤ support × support) gives the centered eigendecomp.
- Eigenvectors of `F_c` in h-space: `V · eigvecs(M)`.

Per-sample cost: one extra eigh on a (≤512 × ≤512) matrix — ~50 ms at support=512, dominated by SVD already in place.

**Smoke test** (`/tmp/smoke_centered_fisher.py`, 2026-05-07) verified all four checks: (1) closed-form `kl_discharged == ½·∂hᵀ F_c ∂h` to 1e-10; (2) centered eigvals match direct `eigh(F_c)` to 1e-9; (3) `Σ kl_per_dir == kl_discharged`; (4) `null_ratio ∈ [0,1]` and monotone non-increasing in rank.

## Decision criteria — pre-registered

After the run, three concrete questions evaluated on each model:

1. **Does centered-Fisher recover Qwen 3?**
   `Δ_Q3 = AUROC(null_ratio_centered_post_rank1) − AUROC(null_ratio_post_rank1)` on Qwen 3 8B.
   - `Δ_Q3 ≥ +0.10` with non-overlap CI ⇒ **[OPEN → confirms hypothesis]**: −ppᵀ correction is the cause of the architectural split. Promote `null_ratio_centered_post_rank1` to v3.3 sealed-primary candidate.
   - `+0.02 < Δ_Q3 < +0.10` ⇒ **[OPEN]**: partial recovery; investigate other geometric corrections (J_n incomplete?) before promotion.
   - `Δ_Q3 ≤ +0.02` ⇒ **[OPEN → falsifies hypothesis]**: centered correction does not explain the split; archive and revisit.

2. **Does centered-Fisher dominate uncentered on the 3-Fisher-wins primaries?**
   `Δ_i` per model ∈ {Llama, Mistral, Qwen 2.5}. Theoretically `Δ_i ≥ 0` (centered uses the proper Fisher); margin uncertain.
   - If any `Δ_i ≤ −0.05` with non-overlap CI ⇒ **[OPEN → calls theory into question]**: investigate before promoting (numerical issues? J_n confound?).

3. **Is `kl_discharged` (single scalar, no rank choice) competitive with rank-r metrics?**
   `Δ_kl = AUROC(kl_discharged) − AUROC(null_ratio_post_rank1)` per model.
   - `|Δ_kl| ≤ 0.05` on all primaries ⇒ **[OPEN → simplifies v4]**: rank choice is decorative; future paper can pre-register `kl_discharged` as the headline metric, eliminating one tunable.
   - Identity prediction: `kl_discharged ≡ 0.5·d_F_full²`, so AUROC should match `pri_v2_full` minus the surprise residualization. Doc-level confirmation that the existing `d_F_full` column is the same quantity in different units.
